## Overview

EdgeSync is a fictional network time synchronization product used to demonstrate an end-to-end documentation workflow.

## Documentation deliverables

- Product requirements and getting started guide
- Architecture and synchronization concepts
- Device, synchronization, and alarm data models
- OpenAPI specification and API reference

## Documentation approach

The project uses structured Markdown, Git version control, consistent terminology, and cross-document reviews to demonstrate a maintainable documentation-as-code workflow.
